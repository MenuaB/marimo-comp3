# Story state machine

The main path has nine required actions: pull back or reduced-motion skip;
choose a training seed; choose its cached proposal; commit the fixed fifty;
reveal released LogD/KSOL; separately reveal Caco-2; inspect a coherent
retrospective card; return to the original seed/proposal; choose one next assay.

The generation context is separate from the fixed retrospective cohort. Seed
changes select a compatible proposal gallery; no later evidence assigns a test
measurement to a generated molecule. Caco-2 cannot appear before the first
laboratory reveal.
