# Before You Make It — state and disclosure contract

The default path has nine required actions. Optional point inspection, replay,
additional proposal cards, methods, and restart do not add required navigation.

| Action | Visitor event | Canonical state change | Observable consequence |
| ---: | --- | --- | --- |
| 1 | Pull back or skip motion | `scale.complete = true` | Counted GDB-17 scale changes context to one real ExpansionRx training record and collection coverage. |
| 2 | Select a seed card | `seed_id`; incompatible `candidate_id` and `next_assay` clear | The real structure, measured seed profile, and compatible cached proposals change. |
| 3 | Select a proposal card | `candidate_id`; `next_assay` clears | The exact cached candidate enters the persistent retained tray with experimental slots unknown. |
| 4 | Scrub a fit | `active_fit_index`, `active_fit_key`, `fit_explored`; focus becomes `E-0024329` | The fixed 256-position nomination layout, fifty-slot tray, fit predictions, and Python overlap update together. |
| 5 | Commit ensemble | `selection_kind = ensemble`; exact canonical `committed_ids` (50); `evidence_stage = prediction` | The ensemble fifty—not the last fit fifty—enter the prediction-only property plane. |
| 6 | Reveal measurements | `measurements_revealed = true`; `evidence_stage = measured` | The same IDs move to measurements; the 25/25 nominee misses LogD while the full result is 41/50 versus 20.949 analytic random expectation. |
| 7 | Expand ADMET | `caco_revealed = true`; `evidence_stage = caco` | The unchanged fifty enter an explicit Papp/efflux plane; 38/50 and 33/41 coverage stays distinct from failure. |
| 8 | Return | `returned_to_proposal = true`; inspected ID becomes the retained candidate | The exact seed/candidate returns beside the measured encouraging examples; no measurements transfer. |
| 9 | Select an assay card | `next_assay` | Python receives a candidate-specific decision record with the question and how its answer could change a decision. |

Generation context (`seed_id`, `candidate_id`) is separate from retrospective
state (`active_fit_key`, `inspected_molecule_id`). Commitment owns the exact
ensemble ID list. Disclosure owns the two booleans. The ending owns
`returned_to_proposal` and `next_assay`.

Changing the seed clears an incompatible proposal and old assay choice but does
not rewrite retrospective evidence. Changing proposal identity never transfers
the previous proposal's data. Fit scrubbing cannot replace a committed list.
The first reveal cannot expose Caco-2; the second cannot occur first. “Restart
retrospective” explicitly clears commitment/disclosure while preserving the
retained proposal. Every event ID and fit key is drawn from the versioned
payload.
